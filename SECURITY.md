# Security

The gate stands between AI agents and paid content, so a way to read a gated page without paying, to make a site
pay or settle something it shouldn't, or to forge a site's calls to Stilebase is a security problem. So is anything
that lets a gate break the site it protects.

## Reporting

Report it privately: on this repository's **Security** tab, choose **Report a vulnerability**. Please don't open a
public issue or pull request for it.

Include what you found, how to reproduce it, and the package and version. We answer within three working days, keep
you posted while we fix it, and credit you in the release notes unless you'd rather we didn't.

## Supported versions

Fixes go into the latest release of each package. Upgrade to it: the gate gets its settings from Stilebase at run
time, so upgrading never changes your configuration.
